# masksvd_exp（実験用）— 結論：効果なし

vision_ws/src/MaskSVD の MaskSVD（MaskNet でモデル点群を計測点群に合わせて削ってから SVD で位置合わせ）を
ROS なしで移植し，バラ積みの T 字管の姿勢推定に効くかを確かめた．効けば，断片ごとの姿勢の一致で
同じ部品かを判定する（セグメンテーションへの応用）予定だったが，前提の姿勢推定で改善が出なかった．

既存コード・vision_ws は編集していない．このフォルダと `scripts/eval_masksvd_pose.py` を消せば元に戻る．

## 評価（正解マスクの点群 146 個，`python scripts/eval_masksvd_pose.py`）

成功：自由空間違反率 < 5%（全周モデルのうちカメラ側を向く面だけで計算．どの手法にも同じ基準）

| 手法 | 成功 | 失敗（>20%） |
|---|---|---|
| 既存 SVD+ICP（カメラ側半分のモデル） | **36%** | 44% |
| SVD のみ（全周モデル） | 6% | 75% |
| MaskSVD（元実装どおり） | 3% | 77% |
| MaskSVD（入力を中心化） | 16% | 64% |
| MaskSVD（中心化＋半径1に拡大＋符号探索＋ICP 1cm） | 19% | 62% |
| 2段階（既存 SVD+ICP の姿勢で重ねて MaskNet で削り，ICP をかけ直す，拡大あり） | 32% | 46% |

## 分かったこと

- **MaskNet にはメートル単位の点群をそのまま入れると働かない**：全モデル点でほぼ同じ確率になる
  （plane の重みで 0.55〜0.58）．ModelNet40 の学習時の大きさ（半径 1 程度）に拡大すると，
  計測点に近いモデル点 0.44／遠い点 0.07 と区別できるようになる（`normalize_scale=True`）．
- それでも既存の SVD+ICP（半分モデル）を上回らない．「カメラ側半分」という手作りの削り方の方が，
  バラ積み（あらゆる向き）では MaskNet の削り方より良い．重み名の「45deg」が示すとおり，MaskNet は
  向きの差が小さい前提で学習されている可能性が高い．
- 学習時の点数（モデル 1024・計測 256）に合わせる，別の重み（45deg，tpipe，pretrained）を使う，でも改善なし．
